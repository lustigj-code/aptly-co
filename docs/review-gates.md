# Review Gates

Labels
- brand, a11y, perf, content, tokens

Required Reviewers
- brand: design lead + brand specialist
- tokens: frontend lead + design lead
- a11y: QA lead
- perf: platform engineer
- content: content/SEO lead

Blocking Criteria
- Off-brand hexes in TSX/CSS
- Buttons not following primary=navy, secondary=teal
- Contrast violations per matrix
- Missing page titles/meta on key pages
- Animations violating policy

Process
- Link PR to audits/ files and design-system-alignment-plan.
- Attach screenshots or Playwright output for visuals.
